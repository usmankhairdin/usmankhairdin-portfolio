CARTHEVIA — PORTABLE STATIC WEBSITE

Upload ALL contents of this ZIP into the chosen hosting folder.
Example: public_html/portfolio/carthevia/
index.html, assets/, fonts/, data/, platform/, solutions/, resources/, pricing/,
sign-in/ and loader-preview/ must stay together as siblings.
The folder may be renamed. This build discovers its own deployment base.

No npm, Node.js service, PHP, database, CDN font or build step is needed on
the hosting server. All browser libraries and assets are bundled locally.
Serve through HTTP/HTTPS static hosting. Browser JavaScript is required.
Opening index.html with file:// is not supported by browser ES-module rules.

22 physical HTML entries support direct entry and page refresh. Ordinary
internal navigation keeps one site session without replaying the loader.

This frontend has no connected authentication, reset email, payment, enquiry
or provider backend. Product workspaces contain illustrative data.

Source remains separately in the local carthevia-commerce project.
